# Django
This is a sample project created using the Django web framework. It demonstrates basic setup, routing, and a simple application to understand how Django functions.

## Features
- Basic Django project structure with routing and views.
- Integration of a simple database using Django ORM.
- Example templates for rendering HTML pages.

## Usage

### If Pipenv is already installed skip this step:
```bash
pip install pipenv
```

### To setup the virtual env to run the project:
```bash
pipenv shell
```

### While to run the code:
```bash
python manage.py runserver
```

## Description about various files:
- **manage.py:** Main entry point for Django project management tasks.
- **Pipfile and Pipfile.lock:**  Contains all the required packages with versions to setup venv.
- **Notes.md:** Contains steps and notes regarding the project and it's workflow.
